API Catalogue

MPact authToken

ConnectAPI

The MPact API returns buy and/or sell market rate data from key market area origin and destination pairs. Rate data can be presented with or without fuel for trailer types of van, reefer, or flatbed.

The data provided by the MPact API includes the following:

  • Average rates over specified time periods
  • Contributor count
  • Order count
  • Min/Max amounts
  • Quartile distribution of rates

Symphony other

API1

The Symphony Mobile Communications service (SMCS) API allows telematics and ELD partners to integrate with customers who use the LoadMaster for Truckload Carriers TMS solution. Its functionality includes, but is not limited to, the following:

  • General Telematics, including tractor/trailer positions, two-way general messages
  • ELD / HOS data delivery to LoadMaster
  • Workflow Dispatch for two-way communication of driver load assignments and dispatch-related driver activities during a trip
  • The posting of driver-captured images into LoadMaster (requires DocumentPower 3rd Party image retrieval)

Quick-Quote authToken

ConnectAPI

The Quick-Quote API allows users to create and retrieve freight quotes for any customer or origin-destination pair. This API supports the accurate assessment of win/loss ratio reports within the system, allowing for the determination of a potential order’s cost and feasibility.

The data provided by the Quick-Quote API includes the following:

  • consignee’s name
  • shipper’s name
  • city
  • state

Order Creation authToken

ConnectAPI

The Order Creation API allows orders to be created by posting Order Requests. Depending on the tenant's configuration, these requests can be auto-accepted or can go through a review process. The Order Creation API provides the means to send new Order Requests, follow up and check on the status of existing requests, and update requests as needed.

Upon acceptance of the order, the Order Creation API provides the ID of the order that has been created.

Access Control authToken

ConnectAPI

Access Control is a fundamental service that all the APIs rely upon to know whether to fulfill a call. Use this API to set up roles and responsibilities (and, most importantly, permissions for those responsibilities). The API can invite new users to take one or more roles, or simply add the user to the role if the user is already known.

Track and Trace authToken

ConnectAPI

The Track and Trace API retrieves a list of all active orders or order information, along with the order's historical details and latest updates. With this API, customers can access important information about the order, such as its shipper, consignee, and any intermediate stops. The Track and Trace API can be used to provide order tracking updates and notifications, allowing for greater transparency and ensuring a quality customer experience.

Vehicle Maintenance authToken

ConnectAPI

The Vehicle Maintenance API enables the exchange of your company’s equipment data with a partnering vehicle maintenance vendor. Its functionality includes, but is not limited to, the following:

  • Listing equipment used in the vehicle maintenance fleet and that equipment’s current operational and maintenance status
  • Listing detailed information and creating records for new equipment added in LoadMaster and updating equipment records as needed.
  • Listing the last thirty days’ worth of preventative maintenance messages for equipment in your fleet.
  • Creating records for preventative maintenance messages in LoadMaster.
  • Listing detailed accounts payable vendor information.

Location Matching authToken

ConnectAPI

The Location Matching API allows users to retrieve and review the information that is associated with all the locations and cities that exist in their system. This allows for locations to be maintained and monitored with greater clarity and transparency, which leads to increased driver and shipment safety. Location and city information can be retrieved individually or as a list, and includes the location’s city, state, geographical coordinates, Google place ID, and other details. Location lists can be filtered as needed by location name, city ID, or postal code.
